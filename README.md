# plotnet

Plot and reshape net text streams with deterministic transforms.

**Site:** https://theworker02.github.io/plotnet/

## Install / run

```bash
git clone https://github.com/theworker02/plotnet.git
cd plotnet
node src/cli.js
node --test
```
